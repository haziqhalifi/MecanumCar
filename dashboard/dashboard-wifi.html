Group 8 The Solar-Powered Farm Harvester

An agricultural robot that transports freshly picked fruit from the fields to the barn, relying on solar power. This dashboard drives the live prototype — the mecanum car below runs the finite-state machine, streaming its state and sensors over WiFi.

Finite-state machine

Sleep Mode → Moving to Field → Loading → Moving to Barn ⇄ Eco-Mode → Waiting for Extraction
Start: Sleep Mode conserves battery · Trigger: light sensor detects sunrise → Moving to Field · Load: waits until weight sensor trips (bin full) → Moving to Barn · Power: solar input drops (cloud) mid-transit → Eco-Mode (slower, non-essential sensors off) · Done: at barn → Waiting for Extraction, signals gantry arm → after transfer, if past sunset → Sleep Mode, else → Moving to Field.

Demo · step-by-step

  1. Sleep Mode (battery conserving) → sunrise detected by light sensor: jitter/init all components → transition to Moving to Field.
  2. At the field, enters Loading: waits until the farmer fills the bin. Once the weight sensor trips (bin full) → Moving to Barn, then turns and transits back.
    • If a cloud drops solar input mid-transit → Eco-Mode: moves slower, non-essential sensors off.
  3. Arrives at the barn and stops → Waiting for Extraction → transmits ready signal to the gantry arm → arm lifts the fruit out of the bin without bruising and signals transfer complete.
    • If after sunset → go to Sleep Mode.
    • If still daylight → return to the field.
Live prototype: the mecanum car maps "field → barn" onto its grid (COLLECTING AREA → DROP zone). Watch the console and live map below as it runs.
